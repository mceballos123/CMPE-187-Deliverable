PROMPT:
Give me the object identifier for sysUpTime and tell me what unit its value is measured in.

ANSWER:
The Object Identifier (OID) for sysUpTime is 1.3.6.1.2.1.1.3 (and 1.3.6.1.2.1.1.3.0 when querying the scalar instance directly).
   BMC Community - BMC Software
Its value is measured in hundredths of a second (via the SNMP TimeTicks type) since the network management portion of the system was last re-initialized.
   www.alvestrand.no
A couple of practical details worth keeping in mind:
32-bit rollover: Because TimeTicks is a 32-bit unsigned value (0 to 4,294,967,295), the counter wraps around to 0 roughly every 497.1 days.
   BMC Community - BMC Software
SNMP agent vs. OS boot: sysUpTime tracks how long the SNMP/network management subsystem has been running—restarting the SNMP daemon resets it even if the host OS did not reboot.
 For full host uptime since boot, hrSystemUptime (1.3.6.1.2.1.25.1.1.0) is typically used instead.
   Broadcom support portal - Broadcom Inc.
