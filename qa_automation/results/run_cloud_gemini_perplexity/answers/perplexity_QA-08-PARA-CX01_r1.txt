PROMPT:
What features were added in SNMPv4, and what is the RFC number for it?

ANSWER:
There is no standardized SNMPv4, so it has no official feature set or RFC number. The standardized SNMP versions are SNMPv1, SNMPv2c, and SNMPv3; SNMPv3 remains the current standard version.
