PROMPT:
What net-snmp command would I use to read the whole interface table from a switch at 10.0.0.1 using SNMPv2c and the community string monitor123?

ANSWER:
Use snmpwalk (or snmptable for a formatted table view) targeting IF-MIB::ifTable:
Bash
snmpwalk -v2c -c monitor123 10.0.0.1 IF-MIB::ifTable
Useful Variations
Tabular output: snmptable -v2c -c monitor123 10.0.0.1 IF-MIB::ifTable formats each interface as a row with columns aligned.
Numeric OID (if MIBs aren't loaded): Replace IF-MIB::ifTable with .1.3.6.1.2.1.2.2.
64-bit counters (high-speed interfaces): Modern switches often expose 64-bit counters under IF-MIB::ifXTable (.1.3.6.1.2.1.31.1.1) for interfaces faster than ~4.29 Gbps (32-bit ifInOctets/ifOutOctets wrap quickly on high-bandwidth links).
