PROMPT:
what is the OID of sysUpTime, and what unit does its vaule use

ANSWER:
The OID of sysUpTime is 1.3.6.1.2.1.1.3 (and when queried as a scalar instance in SNMP GET requests, it is 1.3.6.1.2.1.1.3.0).
   Flamingo
Its value uses TimeTicks, which measures time in hundredths of a second (centiseconds).
   www.alvestrand.no
Key Details to Keep in Mind
What it measures: The time elapsed since the network management portion of the system was last re-initialized—not necessarily since the entire hardware/OS booted.
 If the SNMP daemon/agent restarts on its own, sysUpTime resets to 0 even though the host stayed up.

Alternative for true host uptime: If you need the time since the host itself was last initialized without resetting on an SNMP agent restart, check hrSystemUptime (1.3.6.1.2.1.25.1.1 / 1.3.6.1.2.1.25.1.1.0 in HOST-RESOURCES-MIB), which also uses TimeTicks (hundredths of a second).
