PROMPT:
what net-snmp command wolud I use to read the whole interface table from a switch at 10.0.0.1 uisng SNMPv2c and the community string monitor123

ANSWER:
Bash
snmpwalk -v2c -c monitor123 10.0.0.1 IF-MIB::ifTable
Key Details & Helpful Alternatives
snmpwalk vs. snmptable: snmpwalk recursively queries every OID under IF-MIB::ifTable (.1.3.6.1.2.1.2.2), printing each entry line-by-line. If you prefer a formatted table layout, you can use snmptable -v2c -c monitor123 10.0.0.1 IF-MIB::ifTable.
64-bit counters (ifXTable): Standard ifTable only includes 32-bit counters (such as ifInOctets and ifOutOctets), which can wrap quickly on high-speed interfaces (1 Gbps+). For 64-bit counters (ifHCInOctets, ifHCOutOctets) and interface aliases (ifAlias), walk IF-MIB::ifXTable instead:
Bash
snmpwalk -v2c -c monitor123 10.0.0.1 IF-MIB::ifXTable
Bulk walking (snmpbulkwalk): On switches with many interfaces, snmpbulkwalk is faster because it uses SNMPv2c GETBULK requests:
Bash
snmpbulkwalk -v2c -c monitor123 10.0.0.1 IF-MIB::ifTable
Using numeric OIDs: If MIBs aren't loaded or resolved on your client machine, replace IF-MIB::ifTable with .1.3.6.1.2.1.2.2 (or ifXTable with .1.3.6.1.2.1.31.1.1).
