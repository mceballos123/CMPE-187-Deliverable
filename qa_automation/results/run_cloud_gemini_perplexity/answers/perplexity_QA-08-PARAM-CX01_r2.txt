PROMPT:
Which RFC defines SNMPv5, and what new features did it add?

ANSWER:
No RFC defines SNMPv5: it is not a standardized SNMP version, so there are no “new SNMPv5 features” to list. The standardized SNMP versions are SNMPv1, SNMPv2 (including SNMPv2c), and SNMPv3.

The likely intended version: SNMPv3
SNMPv3 is specified across several RFCs rather than one document. RFC 3410 provides the overview and roadmap; RFCs 3411–3418 define its core framework components. Its main advance over SNMPv2c was security and administration, rather than new management operations.
