PROMPT:
Using net-snmp and SNMPv2c with community monitor123, what command dumps the full interface table of the switch at 10.0.0.1?

ANSWER:
To dump the full standard interface table (IF-MIB::ifTable) from the switch using net-snmp, run snmpwalk:
Bash
snmpwalk -v2c -c monitor123 10.0.0.1 IF-MIB::ifTable
Useful Variations
Numeric OID (if MIBs aren't loaded or resolved):
Bash
snmpwalk -v2c -c monitor123 10.0.0.1 .1.3.6.1.2.1.2.2
Extended interface table (ifXTable) for 64-bit counters and interface names/aliases:
Bash
snmpwalk -v2c -c monitor123 10.0.0.1 IF-MIB::ifXTable
(Numeric OID: .1.3.6.1.2.1.31.1.1)
