PROMPT:
what is the OID of sysUpTime, and what unit does its vaule use

ANSWER:
The OID for sysUpTime (defined in SNMPv2-MIB / RFC 3418) is:
   OID repository
Object OID: 1.3.6.1.2.1.1.3
   OID repository
Scalar Instance OID (when polling/getting): 1.3.6.1.2.1.1.3.0
   OpsRamp Documentation
Unit and Data Type
Its value uses the TimeTicks data type, which represents time in hundredths of a second (
0.01 s).
   www.alvestrand.no
To convert raw ticks to seconds, divide by 100.
To convert raw ticks to days, divide by 8,640,000 (
100×60×60×24).
Practical Caveats
Management subsystem vs. full OS: sysUpTime tracks time since the network management portion of the system was last re-initialized—so restarting the SNMP agent/daemon can reset it without a full device reboot.
 For true host/OS uptime, devices often also expose hrSystemUptime (1.3.6.1.2.1.25.1.1.0).
   BMC Community - BMC Software
+ 1
32-bit rollover: Because TimeTicks is a 32-bit unsigned value, it wraps back to 0 after roughly 497.1 days (4,294,967,295 hundredths of a second).
   BMC Community - BMC Software
