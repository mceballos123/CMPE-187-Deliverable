Give me the object identifier for sysUpTime and tell me what unit its value is measured in.

ANSWER:
The object identifier (OID) for sysUpTime is 1.3.6.1.2.1.1.3. To query its scalar instance with SNMP, use 1.3.6.1.2.1.1.3.0 (sysUpTime.0).

Its value is measured in TimeTicks: hundredths of a second (1 tick = 0.01 seconds). For example, a value of 12345 represents 123.45 seconds. It measures time since the system’s network-management portion was last reinitialized, which is not necessarily time since the device last rebooted.
