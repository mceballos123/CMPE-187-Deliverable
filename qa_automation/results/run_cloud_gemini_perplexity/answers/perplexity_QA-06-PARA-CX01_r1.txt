PROMPT:
SNMPv3 has three security levels. Name them, explain what each one protects, and say which one a company should pick for monitoring in production.

ANSWER:
SNMPv3’s three security levels are noAuthNoPriv, authNoPriv, and authPriv. A company should choose authPriv for production monitoring because it provides both authenticated messages and encrypted monitoring data.

Production recommendation
Use authPriv, preferably with SHA-2 authentication and AES encryption where both the devices and monitoring platform support them. Merely selecting “SNMPv3” is not enough—the configured security level determines whether authentication and encryption are actually used. Cisco explicitly recommends authPriv for secure production deployments.
