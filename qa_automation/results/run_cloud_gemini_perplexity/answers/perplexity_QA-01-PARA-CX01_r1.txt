PROMPT:
In SNMP, what request type is used to pull a big table with as few round trips as possible, and which protocol version added it?

ANSWER:
Use GetBulkRequest (GETBULK), introduced in SNMPv2 and supported by SNMPv2c and SNMPv3, but not SNMPv1. It retrieves multiple successive table entries in one response instead of requiring repeated GETNEXT exchanges, reducing round trips.
