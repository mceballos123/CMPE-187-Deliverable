PROMPT:
Which RFC defines SNMPv4, and what new features did it add?

ANSWER:
No RFC defines SNMPv4: there is no standardized SNMP version 4, so there are no “SNMPv4 features” to list. The standardized versions are SNMPv1, SNMPv2c, and SNMPv3; the SNMPv3 framework is documented in the STD 62 RFC suite.

SNMPv3 is defined across several RFCs, rather than a single document. Its principal improvements over SNMPv1 and SNMPv2c concern security and access control:
