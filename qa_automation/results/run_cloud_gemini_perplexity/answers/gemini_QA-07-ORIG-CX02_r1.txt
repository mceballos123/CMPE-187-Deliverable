PROMPT:
What net-snmp command would I use to read the whole interface table from a switch at 10.0.0.1 using SNMPv2c and the community string monitor123?

ANSWER:
Use snmpwalk (or snmptable for a formatted table view) with the IF-MIB::ifTable object:
Bash
snmpwalk -v2c -c monitor123 10.0.0.1 IF-MIB::ifTable
Useful Variations
Numeric OIDs (no MIB lookup required):
Bash
snmpwalk -v2c -c monitor123 10.0.0.1 .1.3.6.1.2.1.2.2
64-bit interface counters (ifXTable): Standard ifTable uses 32-bit counters that wrap quickly on fast links (1 Gbps+). For high-speed interfaces or interface names (ifName), walk IF-MIB::ifXTable as well:
Bash
snmpwalk -v2c -c monitor123 10.0.0.1 IF-MIB::ifXTable
Cleaner, more compact output: Add -Oq (quick print) or -On (numeric OIDs) if you are parsing output in scripts or want less verbose formatting.
Key Flags Explained
-v2c: Specifies SNMP version 2c.
-c monitor123: Sets the SNMP community string.
10.0.0.1: Target switch IP address.
IF-MIB::ifTable: Walks the entire interface table (ifEntry rows and columns such as ifDescr, ifType, ifOperStatus, and byte/packet counters).
