PROMPT:
What features were added in SNMPv4, and what is the RFC number for it?

ANSWER:
There is no standardized SNMPv4, so there are no officially defined SNMPv4 features and no RFC number for it. The standardized SNMP versions are v1, v2c, and v3; SNMPv3 remains the current standard version.

Security and remote-configuration enhancements for managing SNMP access.
