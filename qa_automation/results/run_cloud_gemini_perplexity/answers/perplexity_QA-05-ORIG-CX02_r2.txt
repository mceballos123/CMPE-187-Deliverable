PROMPT:
What is the difference between an SNMP trap and an SNMP inform?

ANSWER:
An SNMP trap is sent without acknowledgment, so the sender doesn’t know whether the manager received it. An SNMP inform requires the manager to acknowledge receipt; if the acknowledgment doesn’t arrive, the sender can retry.
