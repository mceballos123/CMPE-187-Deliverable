PROMPT:
What is the OID of hrSystemUptime, and what unit does its value use?

ANSWER:
The OID for hrSystemUptime in the SNMP HOST-RESOURCES-MIB is:
1.3.6.1.2.1.25.1.1
Data type: TimeTicks
Unit: Hundredths of a second (1/100 second).
Meaning: Time elapsed since the host was last initialized (booted).
Conversion: 100 ticks = 1 second.
For example, a value of 360000 represents 1 hour.
Note: When querying the scalar instance via SNMP, append .0:
1.3.6.1.2.1.25.1.1.0
