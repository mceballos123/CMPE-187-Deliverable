PROMPT:
Using net-snmp and SNMPv2c with community monitor123, what command dumps the full interface table of the switch at 10.0.0.1?

ANSWER:
Use snmpwalk with SNMPv2c and the IF-MIB interface table OID:
bash
snmpwalk -v2c -c monitor123 10.0.0.1 1.3.6.1.2.1.2.2
-v2c: Uses SNMP version 2c.
-c monitor123: Sets the community string.
10.0.0.1: Switch IP address.
1.3.6.1.2.1.2.2: ifTable OID (interface table).
For extended interface details, including interface names and high-capacity counters, use:
bash
snmpwalk -v2c -c monitor123 10.0.0.1 1.3.6.1.2.1.31.1.1.1
