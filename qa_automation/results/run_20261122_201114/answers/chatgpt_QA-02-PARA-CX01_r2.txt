PROMPT:
Give me the object identifier for sysUpTime and tell me what unit its value is measured in.

ANSWER:
Object Identifier (OID): 1.3.6.1.2.1.1.3.0
Unit: Hundredths of a second (1/100 of a second).
Data type: TimeTicks
Explanation: sysUpTime measures the time elapsed since the network management portion of the device was last initialized.
For example, a value of 12345 represents 123.45 seconds.
Source:
RFC 3418 – SNMP Management Information Base
