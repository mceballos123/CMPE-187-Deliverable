PROMPT:
What is the difference between an SNMP trap and an SNMP inform?

ANSWER:
An SNMP Trap and an SNMP Inform are both messages used by network devices to notify an SNMP monitoring system (NMS) about events or problems.
The biggest difference is:
SNMP Trap: Sends an alert without expecting an acknowledgment.
SNMP Inform: Sends an alert and expects an acknowledgment from the receiving SNMP manager.
1. SNMP Trap
An SNMP Trap is an unsolicited notification sent by a network device to an SNMP manager when an event occurs.
For example:
A router interface goes down.
A switch experiences high CPU usage.
A server encounters a hardware failure.
How it works:
Network Device
Router / Switch
SNMP Trap (UDP 162)
Alert sent to monitoring system
SNMP Manager / NMS
Receives the alert
No acknowledgment is required.
Important: If the trap gets lost due to network problems, the sender does not know that the monitoring system never received it.
2. SNMP Inform
An SNMP Inform is similar to a Trap, but it requires an acknowledgment from the receiving SNMP manager.
How it works:
Network Device
Router / Switch
SNMP Inform (UDP 162)
Sends notification
SNMP Manager / NMS
Receives the notification
Acknowledgment (Response)
Confirms receipt
Network Device
Stops retrying after acknowledgment
If the sender doesn't receive an acknowledgment, it can retransmit the Inform.
This makes Informs more reliable than Traps, although delivery is not absolutely guaranteed.

4. Real-world example
Imagine you're monitoring 100 network switches using SolarWinds or another network monitoring system.
A switch suddenly loses connectivity on one of its interfaces.
Using an SNMP Trap:
The switch detects that the interface is down.
It sends a Trap to the monitoring server.
The monitoring server receives the alert.
No acknowledgment is sent.
Using an SNMP Inform:
The switch detects that the interface is down.
It sends an Inform to the monitoring server.
The monitoring server receives the alert.
The monitoring server sends an acknowledgment.
If no acknowledgment arrives, the switch can retry.
5. Common networking interview questions
Q1: Which is more reliable, Trap or Inform?
SNMP Inform, because it requires acknowledgment and supports retransmission.
Q2: Does an SNMP Trap require acknowledgment?
No. It is sent without requiring an acknowledgment.
Q3: Which transport protocol does SNMP use?
UDP is commonly used for SNMP communications.
Q4: What are the default SNMP ports?
UDP 161: SNMP requests and responses (polling).
UDP 162: SNMP Traps and Informs (notifications).
