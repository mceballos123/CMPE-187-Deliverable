PROMPT:
What net-snmp command would I use to read the whole interface table from a switch at 10.0.0.1 using SNMPv2c and the community string monitor123?

ANSWER:
Use snmpwalk to read the entire interface table:
bash
snmpwalk -v2c -c monitor123 10.0.0.1 1.3.6.1.2.1.2.2
Command breakdown:
snmpwalk — Retrieves multiple SNMP values in a subtree.
-v2c — Uses SNMP version 2c.
-c monitor123 — Specifies the community string.
10.0.0.1 — Switch IP address.
1.3.6.1.2.1.2.2 — Interface Table OID (ifTable).
Useful interface table OIDs:
OID
Description
1.3.6.1.2.1.2.2.1.1
Interface index
1.3.6.1.2.1.2.2.1.2
Interface description
1.3.6.1.2.1.2.2.1.3
Interface type
1.3.6.1.2.1.2.2.1.5
Interface speed
1.3.6.1.2.1.2.2.1.8
Interface operational status
1.3.6.1.2.1.2.2.1.10
Inbound octets
1.3.6.1.2.1.2.2.1.16
Outbound octets
Interview tip: snmpwalk retrieves an entire OID subtree, whereas snmpget retrieves specific OID values.
Only run this against switches you are authorized to monitor. SNMPv2c community strings are transmitted without encryption.
